# 1. Project Overview

## 1.1 Project identity

- **Project:** Campus Finds — Lost and Found Portal
- **Edition:** Basic Syllabus Edition
- **Application type:** Static, client-side web application

## 1.2 Overview

Campus Finds provides a browser-based community board for recording lost and found belongings. A user can submit a listing, browse existing entries, search and filter the board, inspect an item in detail, submit a claim, change a listing's status, and remove an entry. The interface is implemented with HTML5, CSS3, and vanilla JavaScript. Browser LocalStorage holds the data on the current browser and device.

## 1.3 Purpose

The project demonstrates a small, complete interactive application using foundational web technologies. It addresses the practical problem of lost belongings on a campus while keeping the implementation simple enough to inspect and run without a build system or server-side component.

## 1.4 Intended users

The intended users are campus community members who want to post or inspect lost and found listings. Since the application does not provide accounts or shared storage, its current data remains local to the browser that created it.
