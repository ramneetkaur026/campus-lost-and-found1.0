# 6. User Manual

## 6.1 Open the application

Open `index.html` in a modern browser. If LocalStorage is unavailable for a local file, serve the folder with a static HTTP server and open the local URL. No installation step is required.

## 6.2 Create a listing

1. Select **Report an item** in the navigation or scroll to the report form.
2. Choose whether the item was lost or found.
3. Enter the required item, category, location, date, name, and contact details.
4. Optionally add identifying details.
5. Submit the form. A valid listing appears on the board.

## 6.3 Search and filter

Enter a keyword in the board search field. Optionally choose Lost or Found, a category, and a location. These criteria can be applied together. Choose a sort order as needed. Select **Clear filters** to reset the search and filters.

## 6.4 View details and submit a claim

1. Select **View details** on the relevant item.
2. Review its category, location, date, poster information, and description.
3. For an unresolved listing, complete the claim form with your name, contact method, and identifying details.
4. Submit the claim. It is added to that listing's locally stored claim history.

## 6.5 Update status or remove a listing

Use a listing card's status selector to choose Open, Claimed, or Resolved. To remove a card, choose **Remove**. Removal is immediate and cannot be undone through the application.

## 6.6 Data and privacy

Listings and claim details are stored in the current browser's LocalStorage. They are not sent to a server by the application. Anyone with access to the same browser profile and page origin may be able to access or change the local board. Do not use the app to store sensitive information. Clearing the browser's site data removes saved entries.
